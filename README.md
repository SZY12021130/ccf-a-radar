# 📡 CCF-A 论文雷达

CCF-A 类国际学术会议论文雷达站：覆盖 CCF 推荐目录（第七版 · 2026.03）全部 **58 个 A 类会议**，汇集 **2023.01 – 2026.07** 期间发表的 **104,000+** 篇论文，提供主题分布雷达、年度趋势、模糊检索与截稿日历。

**在线访问**：https://szy12021130.github.io/ccf-a-radar/

## 功能

- **总览**：58 个会议卡片、按 10 大 CCF 领域筛选、全局热点主题排行、各年度论文量堆叠图
- **会议雷达**：每个会议的主题雷达图（Top-8 主题）、年份发表趋势、下一届截稿倒计时
- **论文库**：会议内模糊检索（标题/作者）、年份筛选、多维度排序、分页浏览，点击直达原文（DOI/arXiv/出版社页面）
- **主题浏览**：29 个研究主题跨会议分布与论文列表
- **截稿日历**：全部 CCF-A 会议官方截稿时间与倒计时（数据源：CCFDDL）
- **全局检索**：顶部搜索框跨 10 万+ 论文模糊匹配（按 `/` 快速聚焦）

## 数据来源与口径

| 内容 | 来源 |
|---|---|
| 会议名单 | CCF 推荐国际学术会议和期刊目录（第七版，2026 年 3 月） |
| 论文元数据 | Semantic Scholar、OpenAlex、Crossref（三源融合去重） |
| 截稿时间 | [ccfddl/ccf-deadlines](https://github.com/ccfddl/ccf-deadlines)（CCFDDL 小程序同源数据） |

- 覆盖区间 2023.01–2026.07；2026 年部分会议论文尚在收录中，数量为不完全统计
- 主题归类为标题关键词规则模型自动划分，仅供趋势参考
- 个别会议（如 ICLR 2025/2026、CVPR 2025）受索引延迟影响存在缺口

## 本地运行

静态站点，任意 HTTP 服务器即可：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 目录结构

```
index.html          单页应用入口
css/style.css       学术暗色主题样式
js/app.js           路由 / 模糊检索 / ECharts 可视化 / 论文浏览
vendor/echarts.min.js
data/index.json     会议元数据 + 主题 + 截稿信息
data/papers/*.json  各会议论文列表（按需加载）
data/global_index.json  全局检索索引（按需加载）
```
